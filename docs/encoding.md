# Encoding Tools
## Base64 Encode

Encode Unicode text as Base64. Run it as `pyforge run encoding.base64-encode --arguments '{...}'` or select it from the interactive menu.
## Base64 Decode

Decode validated Base64 into UTF-8 text. Run it as `pyforge run encoding.base64-decode --arguments '{...}'` or select it from the interactive menu.
## URL Encode

Percent-encode text for URL components. Run it as `pyforge run encoding.url-encode --arguments '{...}'` or select it from the interactive menu.
## URL Decode

Decode percent-encoded URL text. Run it as `pyforge run encoding.url-decode --arguments '{...}'` or select it from the interactive menu.
## Hex Encode

Encode UTF-8 text as hexadecimal bytes. Run it as `pyforge run encoding.hex-encode --arguments '{...}'` or select it from the interactive menu.
## Hex Decode

Decode hexadecimal bytes as UTF-8 text. Run it as `pyforge run encoding.hex-decode --arguments '{...}'` or select it from the interactive menu.
## HTML Escape

Escape text for safe HTML display. Run it as `pyforge run encoding.html-escape --arguments '{...}'` or select it from the interactive menu.
## HTML Unescape

Resolve HTML entities into Unicode text. Run it as `pyforge run encoding.html-unescape --arguments '{...}'` or select it from the interactive menu.
