# Network Tools
## DNS Lookup

Resolve a hostname to unique local resolver addresses. Run it as `pyforge run network.dns-lookup --arguments '{...}'` or select it from the interactive menu.
## Reverse DNS Lookup

Resolve an IP address to a hostname. Run it as `pyforge run network.reverse-dns --arguments '{...}'` or select it from the interactive menu.
## Local IP Information

Show local hostname and resolver addresses. Run it as `pyforge run network.local-ip --arguments '{...}'` or select it from the interactive menu.
## Network Interface Viewer

List local interface addresses and state. Run it as `pyforge run network.interfaces --arguments '{...}'` or select it from the interactive menu.
## Public IP Viewer

Read the public IP from a minimal HTTPS endpoint. Run it as `pyforge run network.public-ip --arguments '{...}'` or select it from the interactive menu.
## HTTP Header Viewer

Fetch response headers with redirects and timeouts. Run it as `pyforge run network.http-headers --arguments '{...}'` or select it from the interactive menu.
## HTTP Status Checker

Check response status and elapsed time safely. Run it as `pyforge run network.http-status --arguments '{...}'` or select it from the interactive menu.
## URL Parser

Parse and validate HTTP or HTTPS URL components. Run it as `pyforge run network.url-parser --arguments '{...}'` or select it from the interactive menu.
