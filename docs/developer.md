# Developer Tools
## UUID Generator

Generate one or more random UUIDv4 identifiers. Run it as `pyforge run developer.uuid-generator --arguments '{...}'` or select it from the interactive menu.
## Timestamp Converter

Convert ISO timestamps to UTC and Unix time. Run it as `pyforge run developer.timestamp-converter --arguments '{...}'` or select it from the interactive menu.
## Unix Time Viewer

Show current or supplied Unix time in UTC. Run it as `pyforge run developer.unix-time --arguments '{...}'` or select it from the interactive menu.
## Random String Generator

Generate cryptographically strong random text from selected alphabets. Run it as `pyforge run developer.random-string --arguments '{...}'` or select it from the interactive menu.
## Developer JSON Tools

Format JSON through the shared validated JSON service. Run it as `pyforge run developer.json-tools --arguments '{...}'` or select it from the interactive menu.
## Developer Regex Tester

Test regex patterns through the shared text engine. Run it as `pyforge run developer.regex-tester --arguments '{...}'` or select it from the interactive menu.
## Color Converter

Convert between hexadecimal and RGB color forms. Run it as `pyforge run developer.color-converter --arguments '{...}'` or select it from the interactive menu.
## Developer URL Parser

Parse developer URLs through the network validation service. Run it as `pyforge run developer.url-parser --arguments '{...}'` or select it from the interactive menu.
## Cron Expression Explainer

Explain common five-field cron schedules without executing them. Run it as `pyforge run developer.cron-explainer --arguments '{...}'` or select it from the interactive menu.
## Environment Variable Viewer

Filter environment variables while redacting likely secrets. Run it as `pyforge run developer.environment-viewer --arguments '{...}'` or select it from the interactive menu.
## Project Structure Viewer

Render a project tree through the shared file service. Run it as `pyforge run developer.project-structure --arguments '{...}'` or select it from the interactive menu.
## Line-of-Code Counter

Count code, comments, and blanks for common source files. Run it as `pyforge run developer.line-counter --arguments '{...}'` or select it from the interactive menu.
