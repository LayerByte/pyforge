# System Tools
## CPU Information

Report processor counts, frequency, and current load. Run it as `pyforge run system.cpu --arguments '{...}'` or select it from the interactive menu.
## Memory Information

Report virtual memory and swap utilization. Run it as `pyforge run system.memory --arguments '{...}'` or select it from the interactive menu.
## Disk Information

List mounted filesystems and usage statistics. Run it as `pyforge run system.disk --arguments '{...}'` or select it from the interactive menu.
## Operating System Information

Describe the local operating system and architecture. Run it as `pyforge run system.operating-system --arguments '{...}'` or select it from the interactive menu.
## Environment Information

List environment variable names with sensitive values redacted. Run it as `pyforge run system.environment --arguments '{...}'` or select it from the interactive menu.
## Process Viewer

List local processes with bounded output and access handling. Run it as `pyforge run system.processes --arguments '{...}'` or select it from the interactive menu.
## Listening Port Viewer

Show local listening sockets without remote probing. Run it as `pyforge run system.listening-ports --arguments '{...}'` or select it from the interactive menu.
## System Uptime

Report boot time and elapsed uptime. Run it as `pyforge run system.uptime --arguments '{...}'` or select it from the interactive menu.
## Python Environment Information

Show interpreter, prefixes, paths, and virtual environment state. Run it as `pyforge run system.python-environment --arguments '{...}'` or select it from the interactive menu.
