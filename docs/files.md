# Files Tools
## File Information

Inspect file size, type, timestamps, and permissions. Run it as `pyforge run files.information --arguments '{...}'` or select it from the interactive menu.
## File Hash

Calculate a supported digest for a local file. Run it as `pyforge run files.hash --arguments '{...}'` or select it from the interactive menu.
## File Comparison

Compare file metadata and content without modifying either file. Run it as `pyforge run files.comparison --arguments '{...}'` or select it from the interactive menu.
## Duplicate Finder

Group duplicate files by size and SHA-256 content digest. Run it as `pyforge run files.duplicates --arguments '{...}'` or select it from the interactive menu.
## Directory Statistics

Summarize directory counts, bytes, and extensions. Run it as `pyforge run files.directory-statistics --arguments '{...}'` or select it from the interactive menu.
## Directory Tree

Render a bounded text tree for a directory. Run it as `pyforge run files.directory-tree --arguments '{...}'` or select it from the interactive menu.
## File Search

Find files by a case-sensitive glob-style name pattern. Run it as `pyforge run files.search --arguments '{...}'` or select it from the interactive menu.
## Large File Finder

List files meeting a minimum size threshold. Run it as `pyforge run files.large-files --arguments '{...}'` or select it from the interactive menu.
## Empty File Finder

Find zero-byte regular files recursively. Run it as `pyforge run files.empty-files --arguments '{...}'` or select it from the interactive menu.
## File Extension Statistics

Count files by normalized extension. Run it as `pyforge run files.extension-statistics --arguments '{...}'` or select it from the interactive menu.
## File Integrity Snapshot

Create a deterministic SHA-256 manifest without changing files. Run it as `pyforge run files.integrity-snapshot --arguments '{...}'` or select it from the interactive menu.
