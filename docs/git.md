# Git Tools
## Repository Information

Show repository root, branch, remotes, and clean state. Run it as `pyforge run git.repository-information --arguments '{...}'` or select it from the interactive menu.
## Current Branch

Read the checked-out branch or detached state. Run it as `pyforge run git.current-branch --arguments '{...}'` or select it from the interactive menu.
## Branch List

List local branches and identify the current branch. Run it as `pyforge run git.branch-list --arguments '{...}'` or select it from the interactive menu.
## Commit History

Read a bounded recent commit summary. Run it as `pyforge run git.commit-history --arguments '{...}'` or select it from the interactive menu.
## Contributor Summary

Count commits by author from local history. Run it as `pyforge run git.contributors --arguments '{...}'` or select it from the interactive menu.
## Repository Statistics

Summarize tracked file and commit counts. Run it as `pyforge run git.statistics --arguments '{...}'` or select it from the interactive menu.
## Changed Files

List staged and unstaged tracked changes. Run it as `pyforge run git.changed-files --arguments '{...}'` or select it from the interactive menu.
## Untracked Files

List untracked files without changing the index. Run it as `pyforge run git.untracked-files --arguments '{...}'` or select it from the interactive menu.
## .gitignore Checker

Check whether paths are ignored and identify matching rules. Run it as `pyforge run git.gitignore-checker --arguments '{...}'` or select it from the interactive menu.
## Large Tracked File Detector

Find tracked files over a configurable size threshold. Run it as `pyforge run git.large-tracked-files --arguments '{...}'` or select it from the interactive menu.
