# Text Tools
## Text Statistics

Summarize characters, words, lines, sentences, paragraphs, and reading time. Run it as `pyforge run text.statistics --arguments '{...}'` or select it from the interactive menu.
## Word Counter

Count Unicode-aware word tokens. Run it as `pyforge run text.word-count --arguments '{...}'` or select it from the interactive menu.
## Line Counter

Count logical text lines consistently. Run it as `pyforge run text.line-count --arguments '{...}'` or select it from the interactive menu.
## Character Counter

Count Unicode code points with optional whitespace exclusion. Run it as `pyforge run text.character-count --arguments '{...}'` or select it from the interactive menu.
## Duplicate Line Finder

Report repeated lines and their occurrence counts. Run it as `pyforge run text.duplicate-lines --arguments '{...}'` or select it from the interactive menu.
## Text Difference

Produce a unified line-oriented text diff. Run it as `pyforge run text.difference --arguments '{...}'` or select it from the interactive menu.
## Whitespace Cleaner

Trim trailing whitespace and normalize excessive blank lines. Run it as `pyforge run text.whitespace-cleaner --arguments '{...}'` or select it from the interactive menu.
## Case Converter

Convert text to common developer naming styles. Run it as `pyforge run text.case-converter --arguments '{...}'` or select it from the interactive menu.
## Slug Generator

Convert text into a lowercase URL-friendly slug. Run it as `pyforge run text.slugify --arguments '{...}'` or select it from the interactive menu.
## Text Sorter

Sort lines with case and uniqueness controls. Run it as `pyforge run text.sorter --arguments '{...}'` or select it from the interactive menu.
## Text Search

Return numbered lines containing a query. Run it as `pyforge run text.search --arguments '{...}'` or select it from the interactive menu.
## Regex Tester

Compile a regular expression and report matches and groups. Run it as `pyforge run text.regex-tester --arguments '{...}'` or select it from the interactive menu.
