# Hashing Tools
## Text Hashing

Hash UTF-8 text with compatibility and modern digest algorithms. Run it as `pyforge run hashing.text --arguments '{...}'` or select it from the interactive menu.
## File Hashing

Stream a local file into a selected digest. Run it as `pyforge run hashing.file --arguments '{...}'` or select it from the interactive menu.
## Hash Comparison

Compare normalized digest strings in constant time. Run it as `pyforge run hashing.compare --arguments '{...}'` or select it from the interactive menu.
