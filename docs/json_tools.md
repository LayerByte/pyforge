# Json Tools Tools
## JSON Formatter

Pretty-print valid JSON with stable indentation. Run it as `pyforge run json_tools.formatter --arguments '{...}'` or select it from the interactive menu.
## JSON Minifier

Remove insignificant whitespace from valid JSON. Run it as `pyforge run json_tools.minifier --arguments '{...}'` or select it from the interactive menu.
## JSON Validator

Return structured JSON validation details. Run it as `pyforge run json_tools.validator --arguments '{...}'` or select it from the interactive menu.
## JSON Viewer

Flatten JSON values into readable path-value rows. Run it as `pyforge run json_tools.viewer --arguments '{...}'` or select it from the interactive menu.
## JSON Statistics

Count JSON containers, keys, values, and depth. Run it as `pyforge run json_tools.statistics --arguments '{...}'` or select it from the interactive menu.
## JSON Key Search

Find matching object keys and their JSON paths. Run it as `pyforge run json_tools.key-search --arguments '{...}'` or select it from the interactive menu.
## JSON Comparison

Compare parsed JSON and report differing paths. Run it as `pyforge run json_tools.comparison --arguments '{...}'` or select it from the interactive menu.
